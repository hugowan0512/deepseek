一、 前端核心互動流程（6大章節＋日常生活模組）

Screen 1：香江出世紙

輸入稱呼、出生年代（1930s–60s）及成長地區。系統即時計算長者喺每個年齡階段對應嘅香港歷史事件。

Screen 2：六章懷緬＋日常生活篇

除人生大事外，特別加入「第五章：日常生活篇」，提供朝早／晏晝／夜晚作息標籤、飲茶點心、街市買餸與屋企拿手菜記憶卡。

Screen 3：廣東話語音＋AI

Web Speech API (`zh-HK`) 語音轉字 + 原聲保存。AI 針對日常飲食與作息溫柔追問（如拿手菜秘訣），並整理出粵語及書面語雙版本。

Screen 4：有聲自傳＋日常檔案

匯總 6 大章節、專屬「🍵 老友記日常生活檔案」、重要記憶星章（⭐）、原聲播放掣、家人留言館及實體 PDF 列印。

二、 點解「日常生活篇」對長者懷緬治療（防失智）特別重要？

1. 喚醒「程序性記憶」與五感細節

長者即使忘記具體年份，對「煲咩老火湯」、「去茶樓叫咩點心」、「朝早去公園晨運」等日常習慣依然記憶猶新，最容易打開話匣子。

2. 留低屋企「家的味道」俾後代

將阿爺阿嫲嘅一日作息、拿手好菜食譜與過節傳統收錄入自傳，對子孫而言係最親切、最有溫度嘅家族記憶傳承。

GitHub Pages 永久免費託管教學

🐙 點樣用 GitHub Pages 發佈成永久網址（URL）？

📥 第一步：先下載好呢個網站檔案（`index.html`）

撳右邊紅色掣，瀏覽器就會自動幫你將成個遊戲打包下載做一個標準嘅 index.html 檔案！

🐙 第二步：5 個步驟擺上 GitHub Pages（永久免費 + 自動開啟麥克風 HTTPS 權限）

1
建立新倉庫（New Repository）： 登入 github.com/new，喺 Repository name 輸入 hk-memoir，下面一定要揀 Public（公開），然後拉到最底撳綠色掣 Create repository。
2
上傳 `index.html` 檔案： 喺新建立嘅頁面入面，搵藍色字 uploading an existing file 撳入去，將你頭先下載落嚟嘅 index.html 拖拉放落去。
3
儲存變更（Commit）： 等檔案上傳完之後，拉落下面撳綠色掣 Commit changes。
4
開啟 GitHub Pages： 撳頂部選單最右邊嘅 ⚙️ Settings，然後喺左邊側邊欄搵 Pages（喺 Code and automation 下面）。
5
選擇 Main 分支並發佈： 喺 Build and deployment ➔ Branch 下拉選單，將 None 改做 main（隔離保持 / (root)），然後撳 Save！等大約 60 秒重新整理頁面，頂部就會出現你嘅永久網址：
https://你嘅GitHub帳號.github.io/hk-memoir/
